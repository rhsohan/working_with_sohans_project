# PHP Admin Panel

Admin panel built with PHP, MySQL, and jQuery.

## Features
- Admin Login
- Inbox / Messages
- Dashboard
- Theme support

## Setup
1. Clone repo
2. Copy config/config.example.php → config.php
3. Import database
4. Run on XAMPP
